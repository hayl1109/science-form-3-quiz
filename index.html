Deployment & Global Leaderboard Setup

1. Deploying to Vercel

  1. Save this application single file as index.html.
  2. Push the project folder to a GitHub repository or upload directly to Vercel Dashboard.
  3. Select **Static HTML Site** framework preset and click **Deploy**.

2. Firebase Realtime Database Leaderboard

The global leaderboard is connected to the Firebase Realtime Database configured in this file. Scores are saved under /leaderboard and loaded for all visitors.

If scores cannot save or load, check the Realtime Database Rules in Firebase Console. The database must allow the intended read/write access. Do not publish unrestricted write rules for a public site unless you accept that anyone can alter scores.

Vercel does not need extra environment variables for this static HTML implementation.

Database endpoint

https://form3-science-quiz-default-rtdb.asia-southeast1.firebasedatabase.app/leaderboard.json

Firebase configuration is included in this file.
